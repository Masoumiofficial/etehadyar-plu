بسته عملیاتی هوش مصنوعی برای وردپرس: استودیو تولید محتوا و رسانه، بهینه‌ساز محصولات ووکامرس، چت‌بات پاسخ‌گو متصل به پایگاه دانش و صندوق تیکت، و انتشار تلگرام.

== Description ==

**آوند (AvandWP)** یک دستیار اجرایی و عملیاتی هوش مصنوعی برای سایت‌های وردپرسی و فروشگاه‌های ووکامرس است که بدون شعارهای تبلیغاتی غیرواقعی، پنج نیاز روزمره مدیران سایت را در یک محیط فارسی و استاندارد یکپارچه می‌کند:

1. **استودیو محتوا و رسانه (Content & Media Studio):**
   * نگارش پیش‌نویس مقالات سئوشده با ساختار استاندارد HTML (`H2`, `H3`, لیست، جدول و سؤالات متداول).
   * شمارش دقیق کلمات فارسی (مبتنی بر UTF-8) و تکمیل خودکار فیلدهای Yoast SEO و Rank Math.
   * تولید و الصاق تصویر شاخص با DALL-E 3، FAL Flux یا Stability AI.
   * تبدیل متن به پادکست صوتی (`MP3`) و تولید خلاصه آماده انتشار در تلگرام.

2. **دستیار هوشمند ووکامرس (WooCommerce AI Assistant):**
   * اسکن دقیق کاتالوگ محصولات برای یافتن کالاهای دارای توضیحات کوتاه یا فاقد متای سئو.
   * بهینه‌سازی تکی یا دسته‌ای محصولات در صف پس‌زمینه (توضیح کامل، معرفی کوتاه، برچسب‌ها، FAQ Schema و متای سئو).
   * ساخت پیش‌نویس محصول جدید از روی نام و ویژگی‌های اولیه کالا.

3. **چت‌بات پاسخ‌گو و صندوق تیکت پشتیبانی (AI Chat & Support Desk):**
   * پاسخ‌گویی به بازدیدکنندگان بر اساس پایگاه دانش واقعی سایت (نوشته‌ها، برگه‌ها، محصولات و FAQ) همراه با نمایش لینک منبع.
   * پشتیبانی از تایپ صوتی فارسی و ارسال پیام صوتی پشتیبانی (تبدیل به متن با Whisper).
   * امکان ثبت مستقیم تیکت برای کارشناس انسانی همراه با اعلان فوری در تلگرام و ایمیل.

4. **خودکارسازی، تلگرام و ممیزی محتوا (Automation & Telegram):**
   * انتشار خودکار یا دستی نوشته‌ها در کانال تلگرام و اعلان فوری سفارش‌های جدید ووکامرس (با پشتیبانی از پروکسی امن HTTPS برای هاست‌های ایران).
   * ممیزی غیرمخرب نوشته‌ها برای یافتن مطالب فاقد تصویر شاخص، فاقد متای سئو و پیشنهاد لینک‌سازی داخلی.

5. **امنیت، پایداری و شفافیت (Vault, Job Queue & System Health):**
   * ذخیره‌سازی کلیدهای API با رمزنگاری استاندارد `AES-256-GCM`.
   * پشتیبانی هم‌زمان از درگاه ریالی بدون تحریم (`GapGPT`) و سرویس‌های جهانی (`OpenAI`, `Google Gemini`, `Anthropic Claude`) با سوییچ خودکار (Fallback).
   * صف پردازش پس‌زمینه (`Job Queue`) برای جلوگیری از خطای Timeout روی هاست‌های اشتراکی.

== External Services & Privacy Disclosure ==

این افزونه تنها در صورتی که مدیر سایت کلید API مربوطه را در بخش تنظیمات وارد کند، با سرویس‌های خارجی زیر ارتباط برقرار می‌کند:
* **GapGPT (`api.gapgpt.app`)** یا **OpenAI (`api.openai.com`)**: برای تولید متن، تصویر، صوت و امبدینگ.
* **Google Gemini (`generativelanguage.googleapis.com`)** و **Anthropic Claude (`api.anthropic.com`)**: در صورت انتخاب توسط مدیر سایت.
* **FAL.ai (`fal.run`)** و **Stability AI (`api.stability.ai`)**: برای تولید تصویر در صورت تنظیم کلید.
* **Telegram Bot API (`api.telegram.org`)**: برای ارسال پیام به کانال یا گروه تلگرام تعیین‌شده توسط مدیر.

هیچ داده‌ای بدون اقدام مدیر یا کاربر به سرورهای شخص ثالث ارسال نمی‌شود و کلیدهای API به صورت رمزنگاری‌شده در دیتابیس سایت شما نگهداری می‌شوند.

== Installation ==

1. فایل فشرده `avandwp-v1.0.0.zip` را از بخش «افزونه‌ها ← افزودن ← بارگذاری افزونه» در پیشخوان وردپرس نصب و فعال کنید.
2. به منوی **آوند (AvandWP) ← تنظیمات و سلامت** بروید و کلید API خود (مثلاً GapGPT یا OpenAI) را وارد کرده و دکمه «تست اتصال» را بزنید.
3. از منوی **چت‌بات و پشتیبانی ← پایگاه دانش**، دکمه «بازسازی کامل شاخص» را بزنید تا محتوای سایت شما شاخص‌گذاری شود.
